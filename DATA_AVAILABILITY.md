# Suggested Data Availability Statement

The de-identified experimental data, sanitized source code, and analysis scripts supporting this study are publicly available at:

https://github.com/albertsagala/ieee-access-dqn-container-farm

The repository contains DQN deployment logs, distributed-sensor records, actuator and electrical-power measurements, code for DQN training and Jetson Nano deployment, and scripts used to reproduce the reported spatial-validation analyses. Deployment credentials and private network configuration are excluded from the public release.

A DOI-bearing archival release can be added later through Zenodo or another DOI-issuing research repository.
